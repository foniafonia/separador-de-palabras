# Separador de palabras

Tiras con un dedito para que el niño deje **espacio entre palabra y palabra**. Se diseñan en la página (nombre del niño, frase, color, piel, ancho del dedo, largo, zurdos, regla) y se imprimen en A4 apaisado a tamaño real para recortar y plastificar.

**Usar:** https://foniafonia.github.io/separador-de-palabras/

- **Cómo se usa:** animación por pasos (se pausa sola fuera de la vista y con la pestaña oculta; sin movimiento automático si el aparato pide menos movimiento).
- **Pruébalo:** «¿dónde va el hueco?», frases con las palabras pegadas; se toca entre letras y aparece el dedo. Voz del propio aparato.
- **Hazla tuya:** modelo de un dedo en medio o uno en cada punta; dedo de 1, 1,4 o 1,8 cm (el ancho del hueco); tiras de 26, 18 o 13 cm; regla en centímetros reales; blanco y negro para ahorrar tinta.
- **Para acompañar:** hoja de práctica (frase con deditos entre palabras y renglones para copiar) y diploma.
- **Consejos:** plastificar y quitar la ayuda poco a poco (tira grande → normal → pequeña → su propio dedo → sin nada).
- Enlace por canal: `?c=wa|tg|fb|ig|sk|ln`. Con `?yo=1`, un aparato deja de contar. Estadísticas: `estadisticas.html`. Privacidad: `privacidad.html`.
- El nombre del niño no se guarda ni se envía.

Una pieza del laboratorio de **Gabinete Fönia** y **ColmenIA** · [Comunidad de logopedas](https://www.skool.com/logopedia-7339/about)
